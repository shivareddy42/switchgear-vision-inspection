# Annotated real-photo domain-gap examples

These 67 images are resized photographs with model-predicted boxes overlaid.
They illustrate the synthetic-to-photo domain gap described in
[DOMAIN_GAP.md](../../docs/DOMAIN_GAP.md); they are not new ground-truth labels.

[attribution.csv](attribution.csv) records each annotated filename, original
filename, creator, source page, source image URL, license and license URL,
original checksum, retrieval date, and modifications. The original source
register and download log were recovered from the same Cursor store that
produced this review set. Missing creator fields were checked against the
Wikimedia Commons image metadata during the final review.

Each modified photograph retains the license listed in its row. The repository's
MIT code license does not apply to these images. Attribution does not imply
endorsement of the model or its predictions by the photographer.
